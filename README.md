# Estudos Psicológicos

Materiais e ferramentas para apoiar os estudos em Psicologia.

## Plataforma de revisão: Gestão de Pessoas

O site está no arquivo `index.html`. Para publicá-lo pelo GitHub Pages:

1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.

O GitHub Pages exibirá o endereço público do site nessa mesma página. Alterações futuras em `index.html` serão publicadas após serem enviadas para a branch `main`.
